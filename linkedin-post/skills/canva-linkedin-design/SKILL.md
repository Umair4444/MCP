# Canva LinkedIn Design Expert (2026)

This skill provides the design logic, color palettes, and layout strategies needed to create "Proof of Work" visuals in Canva that stop the scroll and satisfy AI search indexing (AEO).

## 1. 2026 Design Standards
- **Aspect Ratio:** Use **4:5 Vertical (1080 x 1350 px)**. It takes up 32% more screen real estate on mobile than 1:1 square.
- **Dwell Time Strategy:** Use **Document Carousels (8-10 slides)**. 
- **Typography:** Use high-contrast, sans-serif fonts (e.g., Montserrat, League Spartan) for headers to ensure AI OCR (Optical Character Recognition) can index your text.
- **Visual Proof:** Incorporate screenshots, hand-drawn diagrams, or data visualizations. Minimalist, authentic "Proof of Work" outperforms stock photos.

## 3. Visual SEO & AEO (AI Readability)
- **Image Filename:** Rename your Canva export to include keywords (e.g., `ai-recruitment-strategy-2026.png`).
- **Alt Text:** Write descriptive alt-text that includes the post's core answer/insight.
- **Safe Zones:** Keep critical text away from the very edges and the bottom 10% (where LinkedIn overlays icons/likes).

## 4. Canva Workflow
1. **Search:** Use the keywords from the table above in the Canva Template search bar.
2. **Apply 2026 Palette:** Update the template colors to match the mapping.
3. **Typography:** Set headers to a bold sans-serif. Use a font size of at least **60pt** for mobile readability.
4. **Layout Check:**
   - **Slide 1:** Big, bold hook text.
   - **Slide 2-7:** One specific insight per slide + visual evidence.
   - **Slide 8:** Clear Call to Action (CTA) pointing to the comment section.

## 5. Design Checklist
- [ ] **Ratio:** Is it 4:5 Vertical?
- [ ] **Contrast:** Can the text be read at 20% brightness?
- [ ] **White Space:** Is there enough "breathing room" around elements?
- [ ] **Branding:** Is your logo or handle consistent on every slide?
- [ ] **Accessibility:** Is the font legible and not overly stylized?
